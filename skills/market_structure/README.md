# Market structure and confirmation

**Model compatibility:** Applies through the `model` inference plugin to both
Jev typed decisions and GenAI/chat models.

This skill focuses the LLM on observed trend, range boundaries, breakout
acceptance or rejection, and the difference between continuation and exhaustion.
It is intended for use alongside available candles, indicators, and derived
market-structure features.

Use it with `--inference-skill market_structure`. The guidance is supplemental;
it cannot add missing data or change the required output format. Structural
features are descriptive and are not confirmed pivots or predictive guarantees.
